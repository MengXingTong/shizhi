# 0.1.2-alpha1 · 2026-11-03

## 用户确认的队列规则（以最后一次纠正为准）

| 操作 | 旧待播 | 新请求 | 其他数据 |
| --- | --- | --- | --- |
| 保存偏好 | 保留 | 不因保存自动重开 | 历史/收藏/当前播报不变 |
| 刷视频 / 重新刷视频 | 移出待播，保留在历史 | 按最新偏好开始新会话 | 不删收藏、不打断当前播报 |
| 暂停刷取 | 保留 | 取消在途，不发起后续模型请求 | 不等于暂停 TTS |
| 继续刷取 | 保留 | 取消完成后恢复按需生产 | 读取已保存的设置 |
| 播放器暂停 | 保留 | 不改变生产控制 | 仅暂停当前 TTS |
| 手动重新提炼一条 | 保留其他待播 | 原生确认后再调用模型 | 成功更新同一条记录和收藏 |

新刷取清理的是 pending 状态，不是 DELETE 历史。旧偏好下的 `seen` 拒绝项重置，已经生成的历史仍去重。单生产者与会话代际仍拒绝晚返回结果；在途取消未结束时不允许重开并发任务。没有每轮请求次数上限。

## 字幕来源错配防护

检查发现的缺口：旧版详情未确认响应 BVID/AID，player 只在字段存在时核对身份；Transcript 不携带来源，模型引用核验只能证明「引用存在于某份字幕」，不能证明这份字幕属于显示标题。前端分页合并也允许旧条目覆盖同 ID 的最新条目。

本次措施：

1. 详情响应必须与请求 BVID 对应，AID 有效，首分P 的 page/CID 与主 CID 一致；不回退使用候选 CID。
2. player 必须完整返回匹配的 BVID/AID/CID；选定轨道要有 ID 和允许的下载地址。正文如自带 BVID/CID，也必须相符。
3. Transcript 冻结视频、字幕行和来源对象；对外只返回副本。摘要使用该来源的权威标题/作者；摘要前与入队前都再次核对身份与指纹。
4. 持久化 BVID/AID/CID、首分P、轨道 ID、资源/正文/输入文本 SHA-256。**不保存含签名的完整 URL、Cookie 或 Key 到历史。** CDN 实际终点仅记录域名供诊断。
5. 不同 BVID 返回已保存条目的相同字幕资源或正文，在模型前就跳过；保存时再校验。此项是保守防护，重复上传相同内容也可能被跳过。
6. 在原摘要调用内要求主题一致并回显 BVID/CID；回复来源不符，即使引用原文正确也不接受。没有新增额外的模型轮次；格式失败不自动重试。
7. 原生最新状态优先于前端分页缓存，防止同 ID 的旧摘要回写显示。

**边界**：未获取用户当次原始响应，未重现手机上那一次串字幕。多数字幕正文不含视频 ID；上述措施验证取数与本地传递一致，不是平台归属的独立证明，模型主题检查也可能判断失误。不能宣称百分之百杜绝平台源数据错配。

## 旧数据与升级

SQLite 表结构/版本不变。启动恢复时仅把缺少来源绑定的旧 queued/active 条目变为 `review`；内容仍在历史，收藏标记和记录 ID 不变。所有未绑定的旧历史也不允许播报。不会自动调用模型重建；用户手动确认「重新提炼」后，成功才替换 payload，保留收藏。失败保留旧摘要，非收藏仍按原有 7 天规则到期。

## 原视频查看

默认从 MainActivity 显式打开非导出的 SourceActivity，加载原 BVID 的第一分P/指定秒数。其远端 WebView 没有 AndroidBridge；不会触发 LoginActivity，也不做登录成功自动 finish。HTTPS 官方页可以导航；bilibili://、intent://、非官方页等不能自动唤起外部应用。忽略网页关闭窗口，只让用户按钮/系统返回退出。页面保留标题栏，支持全屏退出，用户可手动指定浏览器。

并未证实旧版 ACTION_VIEW 瞬返的具体外部处理器原因；这是替换不稳定默认外跳路径，不是伪称已在原设备复现。B 站 H5 是否允许观看完整版、登录或拖到时间点，仍受平台与设备限制。

## 已执行验证

- 52 项 JVM 核心测试（内存 HTTPS 替身，无真实模型调用）。包括 A 被选中/B 被拒、不同 CID/URL/正文、请求与模型输入对应、缺失身份拒绝、跨视频对象拒绝、错误来源回复、冻结对象、重复字幕、旧元数据及深链策略。
- 20 项真实本地资源浏览器 UI 检查（原生桥替身）。包括保存偏好不清队列、新刷/暂停/继续动作分离、历史/收藏保留、来源待复核禁播、BVID/时间点路由、分页缓存优先级及 320/390/736 布局。
- 桌面 SQLite 执行实际建表/清理/移出队列 SQL，验证收藏和当前 active 不变；更新摘要保持行 ID/收藏；偏好拒绝缓存重置。不是 Android instrumentation。
- APK 编译、zipalign、v2/v3 验签；与 0.1.1 的签名证书一致，版本码 3。
- 一次匿名公开视频 metadata 兼容性检查：直连读取 view/player，响应确有 BVID/AID/CID，未使用任何用户账号/凭据，该公开样本无字幕。它不等于已登录个人推荐/字幕验证。

## 必须真机复验

- 覆盖安装后 Key/账号/历史/收藏保留；旧摘要不自动播报、不自动付费修复。
- 有 2–3 条待播时暂停/继续，数量保留；保存新偏好本身不清；点重新刷旧待播移入历史，新内容按新偏好生成，当前音频不中断。
- 同时对照详情 BVID/CID、原视频与引用，验证用户之前出现错配的样本。
- 点击原视频或引用时间点，页面不自动退出；返回、全屏和手动浏览器可用。

此次没有接入用户手机/ADB，没有真实登录/模型/TTS 端到端测试。桌面逻辑、浏览器替身与编译成功不能替代上述验收。
